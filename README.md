# Wireframe App Delivery — Tela de Início

Wireframe de média fidelidade (390×844) da tela inicial de um app de delivery, criado para aplicar os fundamentos e as leis de UX.

## Como abrir

Abra o arquivo `index.html` no navegador. Não há dependências nem build.

## Leis de UX aplicadas

- **Jakob**: busca no topo e tab bar inferior, padrões que o usuário já conhece de outros apps.
- **Fitts**: tab bar e ações principais na zona do polegar; alvos de toque com 44px ou mais.
- **Hick**: só 5 categorias visíveis + "Ver todas".
- **Miller**: tab bar com 4 itens; cada card mostra no máximo 3 dados.
- **Zeigarnik**: o card "Continue seu pedido" lembra a tarefa inacabada.
- **Gestalt (região comum + proximidade)**: cada restaurante é um card; nota, tempo e taxa ficam juntos.
- **Von Restorff**: o único botão escuro da tela é a ação principal.
